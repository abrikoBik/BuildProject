# BuildProject

## Начало работы
```shell
$ make init
```
Далее в новый файл `.env` добавить переменные `POSTGRES_USER` и `POSTGRES_PASSWORD`

## Сборка бэкенда
```shell
$ make build
```

## Запуск бэкенда и базы данных
```shell
$ make start
```

## Остановка бэкенда и базы данных
```shell
$ make stop
```
